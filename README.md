# Black Oystercatcher Data Application

A multi-tier Python desktop application for managing and 
visualizing Black Oystercatcher bird survey data.

## Technologies Used
- Python 3
- Matplotlib (data visualization)
- pytest (unit testing)
- CSV data handling
- N-tier architecture (Presentation, Business, 
  Persistence, Model layers)

## Features
- Load and manage bird survey records
- Sort data using multiple algorithms
- Visualize survey statistics with bar charts
- Full pytest unit test suite
- UUID-based record management

## Project Structure
- business/ — Business logic layer
- model/ — Data model classes
- persistence/ — Data access layer
- presentation/ — UI layer
- tests/ — pytest unit tests

## How to Run
pip install matplotlib
python main.py
